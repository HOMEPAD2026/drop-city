# Pretendard (self-hosted)

Pretendard Variable 1.3.9, dynamic subset (92 woff2 files; a page downloads only the chunks its characters need), copied
from the npm package `pretendard@1.3.9` (dist/web/variable/woff2-dynamic-subset). Copyright (c) 2021 Kil Hyung-jin,
with Reserved Font Name Pretendard — licensed under the SIL Open Font License 1.1 (the licence text is at the top of
pretendard.css; https://github.com/orioncactus/pretendard). Hosted here instead of a CDN so the type is there on the
first paint (the CDN copy arrived after the page drew and every line of text swapped — the site looked like it reloaded).
